AKBAR PRANK PAGE

ISI
- index.html: halaman yang muncul setelah QR dipindai
- monyet.jpg: foto yang ditampilkan

CARA ONLINE GRATIS DENGAN GITHUB PAGES
1. Login ke GitHub dan buat repository baru, misalnya: akbar-prank.
2. Upload index.html dan monyet.jpg ke bagian paling atas repository (root).
3. Buka Settings > Pages.
4. Pada bagian Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder /(root), lalu Save.
6. Tunggu sampai GitHub Pages memberikan URL, biasanya seperti:
   https://USERNAME.github.io/akbar-prank/
7. Buka URL itu di browser untuk memastikan foto dan tulisan tampil.

CARA MEMBUAT QR YANG BERFUNGSI
1. Setelah URL GitHub Pages aktif, salin URL lengkapnya.
2. Buka pembuat QR tepercaya, misalnya https://www.qrcode-monkey.com/
3. Pilih URL/Website, tempel URL GitHub Pages, lalu buat dan unduh QR.
4. Tes QR dengan kamera HP lain sebelum dibagikan.

PENTING
- QR baru bisa dibuat dengan benar setelah URL hosting aktif.
- Jangan menaruh data pribadi di halaman. Ini hanya halaman lelucon sederhana.
- Kalau halaman tidak menampilkan foto, pastikan monyet.jpg dan index.html berada
  di folder/root yang sama dan nama file persis sama.
